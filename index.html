My Projects

02

BIRMINGHAM STUDENT SATELLITE (CUBESAT ADCS)

As a Flight Software Engineer for BSSP, I am engineering the Attitude Determination and Control System (ADCS) for a LEO CubeSat. I implement Kalman Filters to process raw sensor data from magnetometers and gyroscopes to ensure precise satellite orientation stability.

I also collaborate with hardware teams on "Hardware-in-the-Loop" simulations and develop fault-tolerant On-Board Data Handling (OBDH) protocols to ensure reliable data packet transmission in space environments.


AI ENVIRONMENTAL IMPACT ANALYZER

In this project, I Engineered a full-stack AI solution leveraging NLP to assess and quantify the environmental impact of consumer products. The system provided real-time sustainability insights via a responsive React interface, with Flask and MongoDB enabling efficient data processing and storage.

AWS was utilized for scalability and global accessibility, ensuring seamless performance across diverse user bases. This project empowered eco-conscious users and businesses to make informed decisions, promoting sustainability through actionable insights.


LEVERAGING AZURE SENTINEL MAP FOR REAL-TIME CYBER ATTACK DETECTION

In this project, I enhanced cybersecurity capabilities by customizing Azure Sentinel to detect real-time cyber-attacks. By fine-tuning detection rules, optimizing threat-hunting queries, and implementing advanced analytics, I achieved a 20% increase in threat identification and reduced detection time by 15%.

Additionally, I leveraged the Azure Sentinel Map to visualize attack patterns and geolocations, enabling faster analysis and improved situational awareness.
